# ATM Management System 🏧

A simple ATM Management System developed in Python using three connected files for modular programming.

## Project Structure
- `main.py` → Main program execution
- `functions.py` → ATM operation functions
- `data.py` → User account data storage

## Features
- User login authentication
- Check account balance
- Deposit money
- Withdraw money
- Data handling with separate file structure

## How to Run
1. Install Python
2. Clone the repository
3. Make sure all three files are in the same folder
4. Run:

```bash
python main.py
